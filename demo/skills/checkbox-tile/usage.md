# Checkbox tile usage

Product and content decisions shared by every platform. Platform files do
not repeat anything here.

## When to use it

- **Use a checkbox tile** when people can pick several options and each
  option needs a short explanation to choose well, such as notification
  channels or add-on features.
- **Use a plain checkbox** when the label alone is enough.
- **Use a radio tile** when exactly one option can be picked.
- **Use a toggle** when the change takes effect immediately and isn't part
  of a form that gets submitted.

## Grouping

- Always present tiles as a group with a visible group label, such as
  "Where should we send alerts?"
- Keep two to six tiles in a group. With more than six, use a checkbox list.
- Give all tiles in a group the same layout, and either all show icons or
  none do.
- If a group requires at least one choice, say so in the group label or
  helper text, not in each tile.

## Content

- **Heading:** names the option in one to four words, in sentence case,
  without ending punctuation. Example: "Email alerts".
- **Description:** says what picking the option does or costs, in one
  sentence of at most two lines. Example: "Get a summary every morning at
  8 a.m."
- **Icon:** reinforces the heading. If no icon clearly matches every option
  in the group, turn icons off for the whole group.
- Don't put links or other controls inside a tile. The whole tile is one
  control.

## Disabled tiles

Disable a tile only when the option exists but isn't available right now.
Say why nearby, for example in the group's helper text. If the option will
never be available to this person, remove the tile instead.
